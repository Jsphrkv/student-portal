# 🎓 Student Portal System

A full-stack web-based application that allows students and administrators to manage academic information such as course enrollments, payment records, and announcements. Built using **React**, **TypeScript**, **Tailwind CSS**, and **Supabase (PostgreSQL backend)**.

---

## 📌 Features

### 🧑‍🎓 For Students
- Secure login and registration
- View and update personal profile
- See active and past course enrollments
- Check payment status and due dates
- Receive and read admin announcements

### 👨‍💼 For Admins
- Manage student accounts
- Post announcements
- Track student payments
- View enrollment statistics

---

## 🛠️ Technologies Used

### **Languages**
- **TypeScript** – Static typing for JavaScript
- **JavaScript** – Frontend logic

### **Frameworks**
- **React** – Frontend UI framework
- **Tailwind CSS** – Styling framework for rapid design

### **Libraries**
- **Lucide React** – Icon library
- **Supabase JS Client** – API/database communication
- **React Hooks** – State and lifecycle management

### **Database**
- **PostgreSQL** – Used via Supabase

### **IDE**
- **Visual Studio Code** – Code editor for development
